# Forge Mana 1,500 Cap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make 1,500 the absolute level-100 maximum mana total, including all three Mana Pool milestones.

**Architecture:** Keep `PlayerBaseBalanceRules` as the single pure authority for capacity and regeneration. Make `MagicAttributeTarget.MAX_MANA` derive its Forge multiplier from the capped target instead of composing the old configurable `+200%` curve with perk bonuses, then remove the obsolete capacity config path.

**Tech Stack:** Minecraft 1.20.1, Forge 47.4.10, Java 17, Iron's Spells 3.16.2 attributes, JUnit Jupiter 5, Gradle 8.8.

## Global Constraints

- Base maximum mana remains exactly 500 at Mana Pool level 0.
- Maximum mana is exactly 1,500 at level 100 with three milestones and never exceeds 1,500 for clamped valid inputs.
- Milestones remain automatic at levels 25, 50, and 75 and retain a `+3%` base-mana contribution each.
- Mana regeneration remains 1/s at level 0 and exactly 17/s at level 100 with three milestones.
- Iron's Spells remains the sole mana owner; do not create or fill a second mana resource.
- Do not change health, attack damage, spell costs, XP, dungeon logic, network protocol, persistence, or dependency versions.
- Preserve every newer `forge-1.20.1` commit through a non-forced merge before deployment.

public static final double MAX_MANA = 1500.0D;

public static double maxMana(int level, int milestones) {
    int safeLevel = Math.max(0, Math.min(100, level));
    int safeMilestones = Math.max(0, Math.min(3, milestones));

}

public double amount(PlayerStats stats) {
    if (this == MAX_MANA) {
        int level = stats.get(StatType.MANA_POOL).level();
        double target = PlayerBaseBalanceRules.maxMana(
                level, PlayerBaseBalanceRules.manaMilestones(level));
        return target / PlayerBaseBalanceRules.BASE_MAX_MANA - 1.0D;

    return LinearStatScaling.bonus(stats.get(stat).level(), bonusKind.maximumAt100());

    return amount(stats) + bonuses.amount(perkEffect());
}
