# AI Forging Texture Prompt Pack

Date: 2026-07-03
Purpose: exact production prompts for generating the `rough_*` intermediary texture family with ChatGPT Images.

## Usage

Each prompt below is already written to be pasted directly into ChatGPT Images.

Rules:
- generate one item per image
- keep the same family prompt wording for consistency
- change only the material prompt when switching material
- if one result drifts too much, regenerate with the same prompt before editing wording
