# Ordre de test incrémental — Forge 1.20.1

Cet ordre part d'une instance Forge 1.20.1 propre. Le lot 0 reste installé pour tous les essais suivants. Après chaque lot, vérifier le démarrage client et serveur, la création d'un monde, l'enregistrement des sorts/objets et l'absence d'erreurs de mixin ou de registre. Ne passer au lot suivant qu'après validation du précédent.

Les dépendances externes citées viennent de `catalog.csv`. Elles ne font pas partie des 74 JAR couverts ci-dessous et doivent être ajoutées à l'instance lorsqu'elles ne sont pas déjà fournies par le modpack.

## Vérification PowerShell

Exécuter depuis la racine du dépôt :

```powershell
$root = 'external-mods/irons-spells-forge-1.20.1'
$expected = Import-Csv "$root/manifest.csv" | ForEach-Object {
    [pscustomobject]@{ Classification = $_.classification; Filename = $_.filename }
}
$lot = $null
$listed = foreach ($line in Get-Content "$root/test-order.md") {
    if ($line -match '^## Lot (\d+)') { $lot = [int]$Matches[1] }
    if ($line -match '^- \[(active|needs-testing|dependencies)\] `(.+\.jar)`$') {
        [pscustomobject]@{ Lot = $lot; Classification = $Matches[1]; Filename = $Matches[2] }
    }
}

$expectedKeys = $expected | ForEach-Object { "$($_.Classification)|$($_.Filename)" }
$listedKeys = $listed | ForEach-Object { "$($_.Classification)|$($_.Filename)" }
$coverageDiff = Compare-Object $expectedKeys $listedKeys
$duplicates = $listedKeys | Group-Object | Where-Object Count -ne 1
$oversizedLots = $listed | Where-Object Lot -gt 0 | Group-Object Lot | Where-Object Count -gt 5
$badLotZero = $listed | Where-Object {
    ($_.Classification -eq 'dependencies' -and $_.Lot -ne 0) -or
    ($_.Classification -ne 'dependencies' -and $_.Lot -eq 0)
}
$diskNames = Get-ChildItem "$root/active","$root/needs-testing","$root/dependencies" -File -Filter '*.jar' |
    ForEach-Object Name
$diskDiff = Compare-Object ($expected.Filename | Sort-Object) ($diskNames | Sort-Object)

if ($coverageDiff -or $duplicates -or $oversizedLots -or $badLotZero -or $diskDiff) {
    throw 'Couverture, nom, doublon, lot 0 ou taille de lot invalide.'
}

"OK: $($listed.Count) JAR uniques; $((($listed | Group-Object Lot).Count)) lots; lots addons <= 5; 4 dependencies dans le lot 0."
```
